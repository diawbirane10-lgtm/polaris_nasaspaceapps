# POLARIS — Official 30-second NASA Space Apps demo storyboard

A demonstration of under 30 seconds is a permitted submission format. Check the team's Project tab before posting; a longer walkthrough can be supplementary.

| Time | Screen action | Narration (English) | Caption |
|---|---|---|---|
| 0–4 sec | **Mission** view; select Connecting Ridge, show real NASA data. | A lunar landing delay changes everything. | WHAT IF THE LANDING IS DELAYED? |
| 4–10 sec | Go to **Sky**; show Sun/Earth elevations and terrain line. | POLARIS compares sites and dates using NASA Horizons and LOLA topography. | NASA HORIZONS + LOLA |

## Studio notes

- Record exactly what the app shows; do not edit numbers or imply communications are guaranteed.
- If capturing an intermediate build, label it as such.
- Voice in English, calm technical documentary at approximately 130–145 words/minute.
- Avoid long camera transitions; keep only short cuts and subtle UI hover responses.
- Use the real public link in the final slate, with a separate public link to the repository.
- Captions and voiceover text should fit the duration, with breathing room; shorten one phrase if needed.
- Keep an accessible seven-slide backup if the video cannot be produced in time.
